# 数据搜索

天工LCA平台提供强大的全文搜索功能，支持在所有数据模块中进行跨字段搜索。这一特性使天工LCA平台在数据检索能力上显著优于其他LCA平台。

## 搜索功能特点

- **全文搜索**：支持在名称、分类、流属性、输入输出流名称以及系统提取的文本字段中检索
- **智能匹配**：支持模糊搜索、精确匹配和 AI 智能推荐；混合搜索会保留中英文关键词和别名召回，在语义匹配不足时继续使用文本召回
- **范围与筛选**：搜索会按照当前数据来源范围（天工公开数据、商业数据、我的数据或团队数据）和筛选条件返回结果
- **ID 引用查找**：当输入内容是完整 UUID 时，相关数据列表会显示**查找包含该 ID 的数据**，用于定位哪些数据记录在 JSON 中引用了该 ID
- **实时结果**：搜索结果即时呈现，支持多维度筛选和灵活排序

## 搜索示例

### 场景一：过程数据搜索

1. 进入"开放数据"模块
2. 选择"过程"分类
3. 在搜索框中输入"煤炭"
4. 系统将返回所有字段中包含"煤炭"相关内容的匹配结果，包括但不限于名称、分类、输入输出所选择的流的名称等字段

## 注意事项

- 搜索结果受用户权限限制；“我的数据”和“团队数据”搜索只返回当前登录用户有权访问的数据
- 商业数据模块仅显示元数据搜索结果
- 输入中文、英文、常见缩写或 CAS 号时，系统会尽量使用标准别名提升召回稳定性
- 输入完整 UUID 后点击**查找包含该 ID 的数据**，结果会按当前数据来源、团队范围和状态筛选返回，并显示数据类型、名称、版本与 ID；如果没有引用关系，系统会提示没有找到包含该 ID 的数据
- 建议使用标准分类体系以提高搜索效率
