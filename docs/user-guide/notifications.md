# 通知中心

通知中心位于页面右上角顶部工具条，用于集中查看协作邀请、数据审核反馈和问题通知。图标上的数字表示当前未读通知数量。

## 打开通知中心

登录后，点击右上角的**通知中心**图标即可打开弹窗。弹窗顶部提供时间范围筛选：

- **近3天**
- **近7天**
- **近30天**
- **全部**

如果只想处理最近发生的事项，建议先使用近 3 天或近 7 天筛选；排查历史反馈时再切换到全部。

## 通知类型

通知中心包含三个标签：

| 标签 | 主要内容 | 常见处理方式 |
| --- | --- | --- |
| **团队通知** | 团队邀请等协作消息 | 确认邀请来源，并根据团队协作安排处理 |
| **数据通知** | 当前用户提交的数据审核流程状态变更 | 查看审核状态和意见，必要时修订数据 |
| **问题通知** | 他人反馈的数据校验问题通知 | 进入相关数据或问题上下文，确认是否需要跟进 |

首次打开某个标签并加载列表后，系统会更新该类通知的已读时间。下一次未读数量会从新的已读时间之后重新计算。

## 查看数据通知

**数据通知**用于提醒提交者关注审核流程中的状态变化。列表通常包含：

- **名称**：被审核的数据名称
- **团队**：相关团队
- **状态**：例如**已分配**、**已通过**、**已驳回**
- **时间**：通知对应的更新时间
- **操作**：查看或处理该通知

如果状态为**已驳回**，点击**查看**会先打开**审核意见**弹窗。请先阅读审核意见，再决定如何修订数据。

## 修复被驳回的数据

在**审核意见**弹窗中，如果需要修改数据，可以点击**修复数据**。系统会打开对应数据的编辑页面，便于按审核意见调整内容。

如果弹窗显示**暂无审核意见。**，建议回到审核相关页面确认该条记录的上下文，或联系审核管理员补充说明。

## 使用建议

- 每天开始工作前先查看一次通知中心，尤其是**数据通知**。
- 提交审核后，保持关注**已驳回**或需要修订的数据。
- 如果未读数量没有变化，先切换时间范围，再确认是否已经打开过对应标签。
- 通知中心只负责提示和入口跳转；具体的审核角色、分配流程和权限边界请继续阅读[数据审核](./data-review)与[权限与数据空间矩阵](./permissions-and-data-scopes)。
