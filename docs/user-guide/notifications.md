# 通知中心

通知中心集中展示与您相关的协作和数据处理提醒。您可以从页面右上角的通知入口进入，并使用时间筛选查看近 3 天、近 7 天、近 30 天或全部通知。

## 通知类型

通知中心当前按标签页区分三类信息：

- **团队通知**：显示团队邀请。您可以在通知列表中同意或拒绝加入团队。
- **数据通知**：显示您提交的数据在审核流程中的状态变化，包括已分配、已通过和已驳回等状态。
- **问题通知**：显示其他用户反馈的数据校验问题，便于您回到对应数据继续处理。

## 处理数据审核反馈

在**数据通知**标签中，列表会显示数据名称、团队、状态、更新时间和操作入口。

当数据被驳回时，点击**查看**会打开审核意见窗口。请先阅读审核意见，再点击**修复数据**进入对应过程数据的编辑页面。若当前通知没有可显示的审核意见，窗口会提示暂无审核意见。

当数据处于已分配或已通过等非驳回状态时，点击**查看**会以查看模式打开对应的过程或模型数据。

## 使用建议

- 提交数据审核后，优先关注**数据通知**，确认是否需要补充或修复数据。
- 收到团队邀请时，在**团队通知**中处理加入或拒绝操作。
- 收到问题通知时，结合通知中的问题类型回到相关数据页面检查。
- 如果通知列表为空，可以切换时间范围，确认是否只是在当前筛选条件下没有结果。
