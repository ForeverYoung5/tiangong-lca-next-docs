# 通知中心

通知中心位于登录后界面右上角顶部工具条，用于集中查看团队协作、数据审核和问题反馈相关提醒。
如果您只想确认入口位置，可以先查看 [按键功能介绍](./key-functions-introduction)。

## 从哪里进入

点击顶部工具条中的通知图标即可打开通知中心。通知中心是全局入口，不依赖当前所在页面。

通知中心当前包含三个标签：

- **团队通知**：团队邀请等协作提醒。
- **数据通知**：当前账号提交的数据审核状态变化、被驳回数据等提醒。
- **问题通知**：他人反馈的数据校验问题，以及与数据问题相关的处理提醒。

## 时间筛选与已读状态

通知列表支持按时间范围筛选：

- 近 3 天
- 近 7 天
- 近 30 天
- 全部

首次打开某个标签后，系统会更新该类通知的已读时间。建议在开始处理审核、团队协作或问题修复前，
先查看通知中心，避免遗漏需要继续处理的事项。

## 数据通知可以做什么

数据通知通常与数据审核流程相关。列表会展示数据名称、团队、状态、时间和可执行操作。

常见处理方式包括：

- 点击 **View** 查看相关数据。
- 对被驳回的数据，先打开审核意见弹窗查看原因。
- 在审核意见弹窗中点击 **Fix Data**，进入可编辑页面修复数据。
- 修复后回到数据审核流程，根据要求重新提交或等待后续审核。

如果数据通知和 [数据审核](./data-review) 中的状态显示不一致，请以最新打开的详情页和审核管理工作区为准。

## 与其他功能的关系

- 团队邀请通知通常与 [团队功能](./team-function) 相关。
- 数据审核反馈通常与 [数据审核](./data-review) 和 [创建我的数据](./create-my-data) 相关。
- 账号邮箱变更等提醒可能需要同时检查通知中心和邮箱收件箱。
