# 消息中心通知

消息中心会汇总与您相关的数据通知，帮助您及时查看审核结果和需要处理的数据。

## 查看数据通知

进入消息中心后，数据通知列表会显示每条通知的**名称**、**团队**、**状态**、**时间**和**操作**。

常见状态包括：

- **已分配**：数据已分配给相关处理人或审核人。
- **已通过**：数据审核已通过。
- **已驳回**：数据审核未通过，需要查看审核意见并处理。
- **暂无信息**：当前通知没有可展示的状态信息。

点击**查看**时，系统会根据通知状态执行不同操作：

- 对于未驳回的数据，系统会打开对应数据的查看页。
- 对于**已驳回**的数据，系统会先打开**审核意见**弹窗，展示审核人留下的意见。

## 处理已驳回数据

当**审核意见**弹窗打开后，您可以：

1. 阅读审核意见，确认需要修正的内容。
2. 点击**关闭**，先返回通知列表。
3. 点击**修复数据**，在新页面打开对应数据的编辑入口。

如果通知没有可展示的审核意见，弹窗会显示**暂无审核意见。**。

## 注意事项

- 修复数据前，请先确认通知对应的数据名称、团队和状态。
- 打开的查看页或编辑页会保留通知中的数据版本信息。
- 如果您无法处理通知中的数据，请确认自己是否仍属于对应团队，或联系团队管理员。
