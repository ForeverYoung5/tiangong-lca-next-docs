# 消息中心与数据通知

消息中心汇总与协作、审核和平台问题相关的提醒。对于数据作者来说，最需要关注的是
**数据通知**，因为审核通过、审核分配和驳回反馈都会通过这里提示。

## 打开消息中心

登录后，点击右上角顶部工具条中的**消息中心**图标。消息中心当前包含三个标签：

- **团队通知**：团队邀请等协作消息
- **数据通知**：审核相关的数据提醒
- **问题通知**：平台问题或系统动态

可以按最近 3 天、7 天、30 天或全部时间筛选消息。首次打开某个标签后，系统会更新该类消息
的已读时间。

## 数据通知列表

数据通知按表格展示。常见列包括：

| 列 | 含义 |
| --- | --- |
| 名称 | 被审核或被通知的数据名称 |
| 团队 | 相关团队空间 |
| 状态 | 当前审核状态 |
| 修改时间 | 通知记录对应的更新时间 |
| 操作 | 打开详情或处理驳回反馈 |

状态标签通常包括：

- **Assigned**：审核任务已分配
- **Approved**：审核已通过
- **Rejected**：审核被驳回，需要查看反馈
- **No information**：当前通知没有可识别状态

## 查看或修复数据

非驳回状态的记录会提供 **View** 操作。点击后会在新标签页打开对应的数据详情：

- 过程数据会进入 `My Data / Processes` 的查看模式
- 模型数据会进入 `My Data / Models` 的查看模式

如果记录状态为 **Rejected**，点击 **View** 会先打开审核意见弹窗。弹窗中会显示审核评论；
如果没有评论，系统会提示暂无审核意见。确认需要修改后，点击 **Fix Data** 进入可编辑页面。

## 与数据审核配合使用

提交审核后，建议同时关注：

1. [数据审核](./data-review)中的审核状态筛选
2. 消息中心的**数据通知**
3. 审核意见弹窗中的驳回原因

如果数据通知显示驳回，但没有明确评论，请回到审核工作区或联系审核管理员确认需要修订的字段。
