点击右上角头像或用户名，选择**账号信息**，即可进入账户页。

![账号信息](/assets/docs/78a6dc92/account-profile-1.png)

当前账户页包含四个标签：

- **基本信息**
- **修改密码**
- **修改邮箱**
- **生成 API Key**

如果您需要调用远程 MCP 或 OpenAPI，请先在此页生成 API Key，再结合
[天工 LCA MCP（远程）](/zh/docs/integration/mcp-lca-remote/) 或
[TIDAS 数据包导入 API](/zh/docs/openapi/tidas-package-import/) 完成后续配置。

## 基本信息

在**基本信息**中，您可以查看当前邮箱、角色和昵称。

- 邮箱和角色为只读信息，用于确认当前账户身份与权限。
- 昵称可编辑。保存成功后，右上角显示名称会同步更新。

![基本信息](/assets/docs/603f6b1d/basic-information.png)

## 修改密码

修改密码时，系统会要求您填写：

- 当前密码
- 新密码
- 确认新密码

使用时请注意：

- 新密码不能与当前密码相同。
- 新密码必须满足系统当前的复杂度规则。
- 建议修改后立即重新确认常用客户端或自动化脚本中的登录信息。

![修改密码](/assets/docs/3cbfb9d8/change-password.png)

## 修改邮箱

在**修改邮箱**中，系统会显示当前注册邮箱，并要求输入：

- 新邮箱地址
- 确认新邮箱地址

提交成功后，系统会向新邮箱发送验证邮件。完成验证前，请留意[通知中心](/zh/docs/user-guide/notifications/)与邮箱收件箱。

![修改邮箱](/assets/docs/c122399f/change-email.png)

## 生成 API Key

**生成 API Key** 是账户页内的独立标签，不再只在集成文档中说明。

### 适用场景

- 远程连接 TianGong LCA MCP
- 调用需要 API Key 的自动化脚本或服务
- 配置与平台对接的外部工具

### 生成步骤

1. 打开**生成 API Key**标签。
2. 输入当前账户密码，用于再次验证身份。
3. 点击**生成 API Key**。
4. 系统生成成功后，会在页面中显示一次完整 Key。

![生成 API Key 标签](/assets/docs/916b64ab/account-api-key-tab.png)

图中 `1` 为 **生成 API Key** 标签，`2` 为当前密码验证输入框，`3` 为生成密钥按钮。出于安全
原因，本文不展示实际生成后的完整 Key。

### 重要安全提示

> 生成后的 API Key 只会完整显示一次。请立即复制并保存在安全位置，例如密码管理器
> 或受控的密钥管理系统中。

- 如果密码校验失败，系统会提示您重新检查当前密码。
- 如果页面关闭或离开后未保存，您需要重新生成新的 API Key。
- 不要将 API Key 写入公开仓库、截图、工单评论或公共聊天记录。

## 常见问题

### 为什么我在远程 MCP 配置里看到了 API Key，但账号页里没有写？

现在 API Key 的生成入口以账号页为准，远程 MCP 和 OpenAPI 页面只负责说明如何使用
这个 Key，而不再把生成流程藏在集成文档里。

### 账号页里没有“生成 API Key”怎么办？

请先确认您已经登录到正确账号，并刷新页面。如果仍然没有该标签，再联系平台维护者确认
当前环境是否已启用该能力。
