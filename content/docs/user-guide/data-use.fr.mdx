## Consulter les données

1. Ouvrir le panneau de données : repérez la barre de navigation gauche et cliquez sur « Données ouvertes » ou « Données commerciales » pour activer l'interface de gestion des données.
2. Naviguer dans le répertoire de processus : sélectionnez les entrées cibles dans la liste hiérarchique pour accéder à l'espace de données correspondant.
3. Consulter les détails : les listes et résultats de recherche affichent par défaut la dernière version visible de chaque identifiant de jeu de données. Cliquez sur le bouton « Voir » à droite de la liste pour accéder aux informations complètes, notamment :
   - Coordonnées géographiques
   - Plages d'horodatage
   - Limites du système
   - Inventaires d'entrées/sorties
   - Classifications sectorielles et produits
   - [Référence : lignes directrices CIFA, chapitre 6, annexe](https://www.carbonfootprint.network/docs/cifa-guidelines/lca-database-guideline/chapter-6-appendix#product-classification)
4. Consulter l'historique des versions : cliquez sur « Toutes les versions » dans la liste du jeu de données pour accéder à chaque version historique.
5. Consulter les données historiques : cliquez sur « Voir » à côté d'une version pour voir les données historiques détaillées. Lorsqu'une page prend en charge la sélection de version, choisissez la version cible et validez.
6. Inspecter la configuration de base dans **Mes données** : groupes d'unités et propriétés de flux prennent en charge recherche, filtres, Recherche de références, Toutes les versions et export afin de vérifier les enregistrements existants. Les utilisateurs ordinaires n'y voient pas d'actions de maintenance telles que **Créer une version**.
7. Poursuivre le même identifiant : pour créer une nouvelle version à partir d'une version historique, sélectionnez la version source dans **Toutes les versions** et cliquez sur **Créer une version**. Le formulaire indique « La nouvelle version sera générée automatiquement » et le système attribue la version suivante à l'enregistrement. Si vous souhaitez plutôt une copie modifiable indépendante, utilisez **Copier les données**. Pour les opérations de nouvelle version, copie ou autre maintenance des groupes d'unités et propriétés de flux, contactez un administrateur système.

## Citer les données

1. Ouvrir le panneau de sélection : cliquez sur le bouton « Sélectionner » à côté du contenu à citer pour ouvrir le panneau d'information.
2. Changer de catégorie : utilisez la barre de navigation supérieure pour sélectionner d'autres catégories de données.
3. Sélectionner les données : cochez les cases des informations cibles (les lignes sélectionnées sont surlignées en violet). Pour citer une version historique, ouvrez d'abord « Toutes les versions » et sélectionnez la version cible. Les groupes d'unités et propriétés de flux dans **Mes données** prennent aussi en charge la Recherche de références pour trouver les relations, dans les mêmes limites d'espace de données, d'équipe et d'autorisation.
4. Enregistrer : cliquez sur « Enregistrer » en bas de la page d'édition pour revenir au panneau précédent.

> Important : **les données commerciales ne peuvent pas être citées**

## Copier les données

1. Ouvrir le panneau de données : repérez la barre de navigation gauche et cliquez sur « Données ouvertes » ou « Données commerciales ».
2. Naviguer dans le répertoire : sélectionnez les entrées cibles dans la liste hiérarchique.
3. Ouvrir l'interface de copie : cliquez sur « Copier les données » pour ouvrir la page de copie.
4. Enregistrer : cliquez sur « Enregistrer » pour confirmer l'opération de copie.
5. Accéder aux données copiées : rendez-vous dans « Mes données » dans la barre latérale gauche et sélectionnez l'entrée cible pour consulter vos données copiées (modifiables — voir le [Guide Mes données](/fr/docs/user-guide/create-my-data/)).
