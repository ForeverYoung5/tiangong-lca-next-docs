本章节串联 TianGong LCA 的核心使用场景，建议按照「熟悉界面 → 数据流转 → 审核协作 →
权限边界 → 深入分析」的节奏阅读，也方便按需跳转。

## 谁适合阅读

- **数据编写者**：需要新建或维护模型、过程与流，关心字段规范与版本管理。
- **审核与质量负责人**：负责把控数据质量、制定审核标准或追踪审核进度。
- **团队协作成员**：在项目中共享数据、协调权限或管理团队资源。
- **分析与应用用户**：需要检索、引用或分析已有数据集。

## 推荐学习路径

1. **熟悉界面**
   先阅读[按键功能介绍](./key-functions-introduction/)，了解顶部导航、头像菜单、列表操作及常用快捷按钮。

2. **掌握全局导入导出**
   阅读 [TIDAS ZIP 导入、导出与任务中心](./tidas-zip-workflows/)，先弄清顶部 ZIP 工作流和后台任务机制。

3. **理解数据模块**
   通过[数据平台介绍](./data/)掌握开放数据、我的数据、团队数据之间的权限边界。

4. **构建与维护数据**
   依次阅读[数据新建](./create-my-data/)、[数据使用](./data-use/)和[数据搜索](./search/)，学习从准备素材、建模到引用的全流程。

5. **验证与审核**
   在提交前参考[数据审核](./data-review/)的角色分工、审核工作区和检查清单，减少返工。

6. **协作与权限**
   查看[团队功能介绍](./team-function/)、[权限与数据空间矩阵](./permissions-and-data-scopes/)和[系统管理工作区](./system-management/)，明确团队角色、审核角色和系统角色的边界。

7. **深入分析**
   根据需要延伸至[过程分析工作区](./process-analysis/)与[LCIA 计算与结果查看](./lcia/)。

## 常用入口速查

- 想知道顶部哪个入口负责导入、导出和任务进度？转到[按键功能介绍](./key-functions-introduction/)或[TIDAS ZIP 导入、导出与任务中心](./tidas-zip-workflows/)。
- 要创建新的流程或模型？按照[数据新建](./create-my-data/)的“准备工作→构建数据→校验发布”三个阶段完成。
- 提交审核遇到拦截？在[数据审核](./data-review/)查看提交前准备、审核角色与常见问题。
- 需要区分谁能看、谁能改、谁能审核、谁能做系统维护？直接看[权限与数据空间矩阵](./permissions-and-data-scopes/)。
