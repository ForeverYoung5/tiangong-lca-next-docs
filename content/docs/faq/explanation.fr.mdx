## Table de référence des champs de personnes

Exemple : la société A confie à l'institut de recherche B un projet d'analyse de cycle de vie.
L'équipe de recherche (équipe C) est responsable de la production des données, et les informations
du jeu de données sont saisies par le membre de l'équipe (personne D). Une fois les données
terminées, elles sont enregistrées et archivées par l'International Environmental Database
Association (IEDA). La propriété des données finales appartient à la société A, mais seul le groupe
de recherche interne (groupe E) dispose d'un accès exclusif.

| Nom du champ | Description | Type | Exemple |
| :------------------------------------- | :------------------------------------------------------------------------------ | :----------- | :------------------------------------ |
| Commanditaire du jeu de données | La partie qui initie ou finance la collecte de données | Recommandé, sélection multiple | Société A |
| Générateur/Modélisateur du jeu de données | La partie responsable de la collecte ou de la création des données | Recommandé, sélection multiple | Institut B, équipe C |
| Saisie des données par | La personne responsable de la saisie des données | Optionnel, sélection unique | Personne D |
| Autorité d'enregistrement | L'organisation supervisant/enregistrant les données | Optionnel, sélection unique | IEDA |
| Propriétaire du jeu de données | La partie détenant les droits de propriété intellectuelle (peut différer du commanditaire) | Recommandé, sélection unique | Société A |
| Entités à accès exclusif | Personnes/organisations disposant de droits d'accès absolus au jeu de données | Optionnel, sélection multiple | Groupe E |
