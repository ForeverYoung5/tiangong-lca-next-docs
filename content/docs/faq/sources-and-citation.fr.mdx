## Comment garantir la traçabilité des données ?

1. **Enregistrer la source** : dans l'objet Source, renseignez le(s) auteur(s), le titre, la publication, l'année et le DOI/URL.
2. **Téléverser les preuves** : joignez rapports, questionnaires, résultats de laboratoire ou autres pièces justificatives sous « Lien du document électronique ».
3. **Documenter les versions** : utilisez la section « Informations de gestion » pour noter les numéros de version et les résumés de changements.

Voir [Créer mes données](/fr/docs/user-guide/create-my-data/#create-a-source) pour le workflow détaillé.

## Comment la plateforme aide-t-elle à citer de manière cohérente ?

- Les **champs structurés** garantissent que chacun capture les références dans le même format.
- Les **contributions d'équipe** permettent de réutiliser la même source plutôt que de dupliquer les entrées.
- Les **contrôles de revue** dans [Revue de données](/fr/docs/user-guide/data-review/) signalent les références manquantes ou incomplètes avant publication.

## Format de citation recommandé pour les jeux TianGong

> TianGong LCA Platform, Dataset : *Nom du jeu de données*, Version X.Y.Z, consulté le AAAA-MM-JJ, disponible sur [https://lca.tiangong.earth](https://lca.tiangong.earth)

N'hésitez pas à ajouter le contexte du projet ou des notes méthodologiques selon les besoins.

## À quelle fréquence les jeux de données sont-ils mis à jour ?

La plateforme synchronise régulièrement de nouvelles données et méthodes. Consultez la page
[Mises à jour des fonctionnalités](/fr/docs/changelog/function-update/) pour les notes de version.
Les changements majeurs sont également annoncés via le centre de messages.

Une suggestion de modèle de citation ? Envoyez vos retours et nous étendrons cette section.
