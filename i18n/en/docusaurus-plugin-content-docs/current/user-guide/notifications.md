# Notification Center

The Notification Center collects collaboration and data-processing updates that are relevant to you. Open it from the notification entry in the top-right area of the product, then filter notifications by the last 3 days, last 7 days, last 30 days, or all time.

## Notification Types

The Notification Center currently separates notifications into three tabs:

- **Team Notifications**: shows team invitations. You can accept or reject an invitation from the notification list.
- **Data Notifications**: shows review workflow status changes for data you submitted, including assigned, approved, and rejected states.
- **Issue Notifications**: shows validation issues reported by other users so you can return to the related data and address them.

## Handling Data Review Feedback

In the **Data Notifications** tab, the table shows the data name, team, status, update time, and available action.

When data is rejected, click **View** to open the review comment dialog. Read the comment first, then click **Fix Data** to open the related process data in edit mode. If the notification does not include a visible review comment, the dialog shows that no review comment is available.

For assigned, approved, or other non-rejected states, **View** opens the related process or model data in view mode.

## Tips

- After submitting data for review, check **Data Notifications** first to see whether you need to revise the data.
- Use **Team Notifications** to accept or reject team invitations.
- For issue notifications, use the reported issue type to return to the related data page and inspect the problem.
- If the notification list is empty, switch the time range to confirm whether the current filter is hiding older notifications.
