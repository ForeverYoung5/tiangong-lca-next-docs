# Notification Center

The Notification Center lives in the top-right global toolbar. It collects collaboration invites, data review feedback, and issue notifications. The number on the icon shows the current unread count.

## Open the Notification Center

After signing in, select the **Notification Center** icon in the top-right toolbar. The modal includes a time filter:

- **Last 3 Days**
- **Last 7 Days**
- **Last 30 Days**
- **All**

Use the shorter ranges for daily work, then switch to **All** when you need to find older feedback.

## Notification types

The Notification Center has three tabs:

| Tab | Main content | Typical action |
| --- | --- | --- |
| **Team Notifications** | Team invitations and collaboration messages | Check the invitation source and respond according to your team workflow |
| **Data Notifications** | Status changes from review workflows for data you submitted | Review the status and feedback, then revise data if needed |
| **Issue Notifications** | Validation issue notifications reported by other users | Open the related data or issue context and decide whether follow-up is needed |

After you open a tab and its list loads, the platform updates that notification type's viewed timestamp. Future unread counts are calculated from the new viewed time.

## Review Data Notifications

**Data Notifications** help authors follow review status changes. The list typically includes:

- **Name**: the reviewed data item
- **Team**: the related team
- **Status**: for example **Assigned**, **Approved**, or **Rejected**
- **Time**: when the notification was updated
- **Actions**: view or handle the notification

When the status is **Rejected**, selecting **View** first opens the **Review Comment** modal. Read the feedback before deciding how to revise the data.

## Fix rejected data

In the **Review Comment** modal, select **Fix Data** when you need to edit the submitted data. The platform opens the related data in edit mode so you can apply the review feedback.

If the modal shows **No review comment available.**, return to the review context for that record or ask the review admin for more detail.

## Practical tips

- Check the Notification Center at the start of each workday, especially **Data Notifications**.
- After submitting data for review, watch for **Rejected** records that need revision.
- If the unread count does not change, adjust the time range and confirm whether you have already opened that tab.
- The Notification Center is a reminder and navigation surface. For review roles, assignment flow, and permission boundaries, continue with [Data Review](/en/user-guide/data-review) and [Permissions & Data Spaces](/en/user-guide/permissions-and-data-scopes).
