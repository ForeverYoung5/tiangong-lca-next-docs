# Notification Center

The notification center collects data notifications related to you, so you can review outcomes and act on data that needs attention.

## View Data Notifications

The data notification list shows each notification's **Name**, **Team**, **Status**, **Time**, and **Actions**.

Common statuses include:

- **Assigned**: the data has been assigned to a relevant owner or reviewer.
- **Approved**: the data review has passed.
- **Rejected**: the data review did not pass, and you should review the comment before fixing it.
- **No information**: the notification has no status information to display.

When you click **View**, the system responds based on the notification status:

- For data that is not rejected, the system opens the matching data view page.
- For **Rejected** data, the system first opens a **Review Comment** dialog with the reviewer's comment.

## Handle Rejected Data

When the **Review Comment** dialog opens, you can:

1. Read the review comment and confirm what needs to be corrected.
2. Click **Close** to return to the notification list.
3. Click **Fix Data** to open the matching data edit entry in a new page.

If no review comment is available, the dialog shows **No review comment available.**.

## Notes

- Before fixing data, confirm the notification's data name, team, and status.
- Opened view or edit pages preserve the data version carried by the notification.
- If you cannot act on the data in a notification, confirm whether you still belong to the relevant team or contact a team administrator.
